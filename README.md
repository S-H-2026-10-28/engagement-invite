# دعوة خطوبة سعيد وهديل

موقع ثابت (HTML/CSS/JS) بلا أي مكتبات أو خدمات مدفوعة، والخطوط مستضافة داخل المشروع.

## الملفات
- `config.js` — **كل البيانات القابلة للتعديل** (الموعد، القاعة، الخريطة، الموسيقى).
- `index.html` — المحتوى ووسوم المشاركة (العنوان، الوصف، صورة المعاينة).
- `style.css` — التصميم · `script.js` — المنطق · `og.jpg` — صورة المعاينة 1200×630 · `fonts/` — الخطوط (رخصة OFL).

## قبل النشر
1. عبّئ `config.js`:
   - `eventDate: '2026-12-24T19:30'` (بتوقيت السعودية، يُحسب العداد تلقائيًا ويتحوّل لرسالة تهنئة عند حلول الموعد).
   - `venueName`, `venueAddress`, `mapsUrl` (رابط مشاركة Google Maps).
   - `musicUrl: 'music.mp3'` (اختياري: ضع الملف في المجلد نفسه؛ لا تعمل إلا بعد ضغط «افتح دعوتك»).
2. بعد النشر: غيّر `og:image` و`twitter:image` في `index.html` إلى رابط كامل مثل `https://your-site.netlify.app/og.jpg` (واتساب يحتاج رابطًا مطلقًا لإظهار الصورة).

## النشر (اختر واحدًا)
**Netlify (الأسهل):** افتح app.netlify.com/drop واسحب مجلد المشروع كاملًا ← تحصل على رابط فوري. من Site settings يمكنك تغيير الاسم.

**GitHub Pages:** أنشئ مستودعًا عامًا، ارفع الملفات للجذر، ثم Settings ← Pages ← Source: `main` / root. الرابط: `https://USER.github.io/REPO/`.

**Vercel:** `npx vercel` داخل المجلد، أو استورد المستودع من vercel.com (بدون إعدادات بناء).

## اختبار سريع
- افتح الرابط من هاتف خارج شبكتك (بيانات الجوال).
- أضف `#open` لنهاية الرابط لتخطّي الظرف أثناء المراجعة.
- لتحديث صورة المعاينة في واتساب بعد التعديل استخدم developers.facebook.com/tools/debug.
